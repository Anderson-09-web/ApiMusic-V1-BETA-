# 🎵 ApiMusic V1 BETA

API y sistema de música para Discord basado en Python, discord.py, Wavelink, FastAPI y Lavalink.

## ✨ Características

- 🤖 Discord Music Bot
- 🎧 Lavalink 4.2.2
- 🌐 FastAPI
- 🔎 Búsqueda y reproducción
- 📋 Sistema de cola
- 🎛️ Panel interactivo de música
- 🔁 Modos de repetición
- 🔀 Shuffle
- 🔊 Control de volumen
- ⏸️ Pausa y reanudación
- ⏹️ Detener reproducción
- 🎵 Plugin de YouTube para Lavalink

## 🛠️ Tecnologías

- Python 3.12
- discord.py 2.7.1
- Wavelink 3.5.2
- FastAPI
- Uvicorn
- aiohttp
- python-dotenv
- Lavalink 4.2.2

## 🔐 Variables de entorno

DISCORD_TOKEN=
LAVALINK_URI=
LAVALINK_PASSWORD=
MUSIC_API_URL=

Nunca publiques tu archivo .env ni tokens privados.

## ☁️ Render

El proyecto está preparado para utilizar tres servicios independientes:

1. Music API con FastAPI
2. Discord Bot como Worker
3. Lavalink mediante Docker
